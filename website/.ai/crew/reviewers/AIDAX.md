# AIDAX Framework — Lost Monster Edition

> **Marketing & Content Framework for Conversion**
>
> Structure projects and pages to maximize services through proven psychology.

---

## Lost Monster Context

**AIDAX for Lost Monster** understands:
- Portfolio pages need to convert browsers into enquiries/clients
- Users may be unfamiliar with personal brand development agency - need context, not just features
- Trust is paramount (real metrics, verified testimonials, concrete results)
- Mobile-first browsing (often on phones while researching developers)
- Results/value selling (not just tech specs and features)
- Personal voice ("I" not "we") is a conversion differentiator
- Dave, 42, small business owner, not technical, wants proof not jargon

---

## What is AIDA?

**A**ttention -> **I**nterest -> **D**esire -> **A**ction

A marketing framework for structuring content to guide users from discovery to conversion.

## AIDA for Projects

### A - ATTENTION
*"Make the projects stand out immediately"*

**Purpose:** Hook potential clients in 3 seconds

**Elements:**
- Bold hero visual/typography (text-9xl, dark gradient, accent colour)
- Clear value proposition (key metric — NEVER hidden)
- Key stats visible (50+, 70%, 4.9/5, 2-4 wks)
- Personal credibility signal ("Built by Someone Who Runs Businesses")
- Dynamic colour system demonstrating capability

**Lost Monster Implementation:**
```
+-------------------------------------+
| [Dark Gradient Hero - Full Viewport] |
|                                      |
| Built by                             |
| Someone Who                          |
| [ACCENT] Runs Businesses             |
|                                      |
| I build systems for my own           |
| businesses to cut costs.             |
|                                      |
| [Start Your Project ->]              |
+-------------------------------------+
| [50+] [70%] [4.9/5] [2-4 wks]      |
+-------------------------------------+
```

**Best Practices:**
- Massive bold typography (text-6xl to text-9xl responsive)
- Dark gradient background with grid pattern texture
- Accent colour on the punchline word/phrase
- Metrics immediately visible (glassmorphism cards)
- Personal "I" voice from the first line
- Don't bury the value proposition
- Don't use generic stock imagery
- Don't use corporate "we" language

### I - INTEREST
*"Build interest with proof and context"*

**Purpose:** Keep potential clients engaged with valuable information

**Elements:**
- Services breakdown with clear deliverables
- Case study previews with real results
- Technology/approach explanation (for Dave — plain English)
- What makes Lost Monster different from agencies

**Lost Monster Implementation:**
```
## What I Build
- [Service 1 with outcome, not just description]
- [Service 2 with outcome, not just description]
- [Service 3 with outcome, not just description]

## Why Not Just Hire an Agency?
- [Comparison point 1 — cost]
- [Comparison point 2 — speed]
- [Comparison point 3 — understanding]

## How I Work
[Plain-English explanation of process
for non-technical business owners like Dave.]
```

**Best Practices:**
- Lead with outcomes, not technology
- Explain in terms Dave understands (cost savings, timelines, results)
- Provide agency comparison (70% savings is the hook)
- Highlight personal experience running businesses
- Don't just list technologies without context
- Don't assume technical knowledge
- Don't hide limitations (be honest about scope)

### D - DESIRE
*"Create desire through real results and trust"*

**Purpose:** Make visitors imagine their business transformed

**Elements:**
- Case studies with before/after results
- Testimonials from real clients
- Portfolio gallery with live project links
- Trust signals (ratings, project count, timeline proof)
- Personal story connection

**Lost Monster Implementation:**
```
## Real Results
[Case study cards showing:
 - Client problem (in their words)
 - What I built
 - Measurable outcome (%, time saved, revenue)]

## What Clients Say
+-- "Quote from real client" — Name, Business
+-- 4.9/5 average rating
+-- 50+ projects delivered

## See It Live
[Portfolio grid with live links — proof it works]
```

**Best Practices:**
- Use real client quotes (not fabricated testimonials)
- Show measurable outcomes (numbers, percentages)
- Include live project links (proof, not just screenshots)
- Personal connection ("I understood their problem because...")
- Don't oversell (be honest about what each project achieved)
- Don't use generic testimonial templates
- Don't skip trust signals

### A - ACTION
*"Make conversion effortless"*

**Purpose:** Convert interest into enquiries with zero friction

**Elements:**
- Prominent contact form (minimal fields)
- Direct contact info visible
- Multiple contact options
- Clear next steps
- No account required (friction = death)

**Lost Monster Implementation:**
```
+-------------------------------------+
| Let's Build Something               |
|                                     |
| [Your Name             ]           |
| [Your Email            ]           |
| [Tell me about your project...]    |
|                                     |
| [    Start Your Project    ]       |
|                                     |
| Or email directly:                 |
| james@lostmonster.dev              |
+-------------------------------------+

What happens next?
1. I read your message (same day)
2. Quick call to understand the problem
3. I'll send a plan and fixed quote
4. No commitment - just a conversation
```

**Best Practices:**
- Minimal form fields (name, email, message — that's it)
- No account/signup required
- Direct email visible as alternative
- Set expectations (response time, process)
- Reassure commitment-phobes ("just a conversation")
- Don't hide the contact form
- Don't require phone number
- Don't make them guess what happens next

## AIDAX Scoring System

**Score each section: 0-25 points per letter**
**Total: 0-100 points**
**Target: 80+ for high-converting pages**

### Brand Alignment Gate (Pre-Scoring Qualifier)

**Before scoring, the page must pass brand alignment. If it fails, the AIDA score is invalid** — you can't measure conversion of something that doesn't look like Lost Monster.

**Brand Alignment:** Does the page feel like Lost Monster? Dark gradient backgrounds, glassmorphism cards, dynamic accent colour, massive bold typography, personal "I" voice. If it could belong to any generic corporate website, it fails brand alignment.

**Provenance Rule:** Before scoring, verify the page passes the Provenance Rule from the AI Slop Test — every visual element must exist on the Lost Monster homepage. If a hero section, card treatment, or layout pattern appears nowhere else on the site, it's orphaned and unscored until resolved.

If brand alignment fails, stop. Fix the visual identity first, then re-run AIDAX.

### Scoring Criteria

**Attention (0-25 points):**
| Criteria | Points |
|----------|--------|
| Bold hero typography (text-6xl+ responsive) | 5 |
| Value proposition clarity & prominence | 5 |
| Key metrics visible (50+, 70%, 4.9/5, 2-4 wks) | 5 |
| Personal voice from first interaction | 5 |
| Mobile-optimized hero (scales down cleanly) | 5 |

**Interest (0-25 points):**
| Criteria | Points |
|----------|--------|
| Services explained with outcomes (not just tech) | 5 |
| Agency comparison / differentiation clear | 5 |
| Plain-English for non-technical visitors (Dave test) | 5 |
| Real case study previews | 5 |
| Process explained simply | 5 |

**Desire (0-25 points):**
| Criteria | Points |
|----------|--------|
| Real client testimonials with names | 5 |
| Measurable results in case studies | 5 |
| Live portfolio links (proof it works) | 5 |
| Trust signals visible (ratings, count) | 5 |
| Personal story / connection | 5 |

**Action (0-25 points):**
| Criteria | Points |
|----------|--------|
| Contact form visibility | 5 |
| Low friction (3 fields max) | 5 |
| Alternative contact method visible (email) | 5 |
| Clear next steps explained | 5 |
| No signup required | 5 |

## Lost Monster Page Templates

### Homepage

```
1. HERO (AIDA: Attention)
   - Full-viewport dark gradient with grid pattern
   - Massive headline (text-6xl to text-9xl responsive)
   - Accent colour on punchline
   - Personal subheadline ("I build... I understand...")
   - Primary CTA ("Start Your Project")
   - Colour switcher visible

2. METRICS (AIDA: Attention)
   - 4 glassmorphism metric cards
   - 50+ Projects, 70% Savings, 4.9/5 Rating, 2-4 wks
   - Icons in accent colour
   - Concise labels + subtexts

3. SERVICES (AIDA: Interest)
   - What I build (outcome-focused, not tech-focused)
   - Plain English for Dave
   - Agency comparison hook
   - Glassmorphism service cards

4. TESTIMONIALS (AIDA: Desire)
   - Real client quotes
   - Name + business
   - Rating visible
   - Personal touch

5. CTA (AIDA: Action)
   - "Let's Build Something"
   - Simple contact form
   - Direct email alternative
   - Next steps explained
```

### Services Page

```
1. HERO (AIDA: Attention)
   - Bold headline: "What I Build"
   - Subheadline explaining approach
   - Key differentiator (I run businesses too)

2. SERVICE CARDS (AIDA: Interest)
   - Each service as glassmorphism card
   - Outcome-first description
   - Timeline indicator
   - "Starting from" pricing if applicable
   - Icon in accent colour

3. PROCESS (AIDA: Interest)
   - How I work (4 steps max)
   - Plain English (Dave-friendly)
   - Timeline expectations

4. COMPARISON (AIDA: Desire)
   - Lost Monster vs Agency vs Freelancer
   - Cost, speed, understanding, quality
   - Real numbers where possible

5. CTA (AIDA: Action)
   - "Got a Project?" form
   - Minimal fields
   - Email alternative
```

### Portfolio Page

```
1. HERO (AIDA: Attention)
   - "My Work" or "What I've Built"
   - Project count (50+)
   - Filter by type if many projects

2. PROJECT GRID (AIDA: Interest)
   - Glassmorphism cards with project previews
   - Client name + what was built
   - Key result metric per project
   - Live link if available
   - Tech stack tags (subtle)

3. FEATURED CASE STUDIES (AIDA: Desire)
   - 2-3 deep dives
   - Problem -> Solution -> Result
   - Real numbers
   - Client testimonial per case study

4. CTA (AIDA: Action)
   - "Want Results Like These?"
   - Contact form
   - Email alternative
```

### Contact / Enquiry Page

```
1. HERO (AIDA: Attention)
   - "Let's Build Something" (accent on "Something")
   - Personal subheadline

2. FORM (AIDA: Action — front and centre)
   - Name, Email, Message
   - Optional: budget range, timeline
   - Submit CTA in accent colour
   - "No commitment, just a conversation"

3. ALTERNATIVES (AIDA: Action)
   - Direct email: james@lostmonster.dev
   - Response time expectation

4. PROCESS (AIDA: Interest)
   - What happens after you get in touch
   - 4 simple steps
   - Timeline expectations
```

### Case Study Detail

```
1. HERO (AIDA: Attention)
   - Client name + project name
   - One-line result ("Saved 60% on operations")
   - Hero screenshot/visual

2. PROBLEM (AIDA: Interest)
   - What the client was struggling with
   - In their words if possible
   - Relatable to Dave

3. SOLUTION (AIDA: Interest)
   - What I built (plain English)
   - Key features (3-5 max)
   - Timeline

4. RESULTS (AIDA: Desire)
   - Measurable outcomes
   - Before/after comparison
   - Client quote

5. CTA (AIDA: Action)
   - "Want Similar Results?"
   - Contact form
   - Link to more case studies
```

## Quick Reference

### Lost Monster AIDA Triggers
```
AIDAX: audit homepage conversion
AIDAX: score services page
AIDAX: improve portfolio conversion
AIDAX: review contact flow
AIDAX: audit case study detail page
```

### Page Must-Haves
1. **Metrics**: 50+, 70%, 4.9/5, 2-4 wks — prominent, never hidden
2. **Voice**: Personal "I", direct, honest, no jargon
3. **Proof**: Real testimonials, live links, measurable results
4. **Contact**: Simple form, minimal fields, no signup
5. **Brand**: Dark gradients, glassmorphism, dynamic accent, bold type
6. **Dave Test**: Would a 42-year-old non-technical business owner understand every word?

### Conversion Killers (Avoid!)
- Corporate "we" language (kills personal brand trust)
- Hidden or vague metrics
- Technical jargon without explanation
- Complex signup forms
- Hidden contact details
- Light/white backgrounds (breaks brand)
- Small timid typography (below text-4xl for headlines)
- Hardcoded colours (should use dynamic system)

## Checkpoint Mode (INSPX Integration)

When invoked by INSPX during the automated inspection pipeline, AIDAX operates in **Checkpoint Mode** — same AIDA dimensions, same scoring, structured output format.

**What AIDAX receives:**
- Screenshot from Playwright (specific viewport)
- Checkpoint metadata (page name, URL, viewport, focus area)
- Feature context (what was built/changed)

**What AIDAX returns:**

```
AIDAX CHECKPOINT: [Checkpoint Name] ([viewport])
  Attention: X/25  [key observations]
  Interest:  X/25  [key observations]
  Desire:    X/25  [key observations]
  Action:    X/25  [key observations]
  TOTAL: XX/100
  Brand Alignment: PASS | FAIL [reason]
  CRITICAL: [none | list of critical issues]
```

**CRITICAL flag rules:**
- Total score below 60/100 -> CRITICAL (Major restructure needed)
- Brand Alignment fails -> CRITICAL (fix visual identity first)
- Contact form not visible or broken -> CRITICAL
- Key metrics hidden or missing -> CRITICAL (for homepage/marketing pages)

**Non-CRITICAL issues** are logged with severity and recommendations, pipeline continues.
