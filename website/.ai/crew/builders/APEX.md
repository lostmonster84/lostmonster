## APEX Modes

### Full APEX (Default)
**Command:** `APEX: [feature]`
**Executes:** All 6 stages
**Use for:** Major features (search, projects management)

### Partial APEX Modes

#### APEX-STATIC
**Command:** `APEX-STATIC: services landing page`
**Skips:** CRUDX (Stage 3)
**Use for:** Static content pages (About, How it Works, Contact)

#### APEX-DESKTOP
**Command:** `APEX-DESKTOP: admin analytics dashboard`
**Skips:** TUCHX (Stage 5)
**Use for:** Admin dashboard features (desktop-first)

#### APEX-BACKEND
**Command:** `APEX-BACKEND: projects status automation`
**Skips:** AIDAX, TUCHX, SOFAX (Stages 4-6)
**Use for:** Backend automation (notification emails, webhooks)

#### APEX-FRONTEND
**Command:** `APEX-FRONTEND: projects comparison view`
**Skips:** CRUDX (Stage 3)
**Use for:** Frontend features using existing APIs

## Quick Reference

### Commands
- `APEX: [feature]` - Full execution (all 6 stages)
- `APEX-STATIC: [feature]` - Skip backend
- `APEX-DESKTOP: [feature]` - Skip mobile
- `APEX-BACKEND: [feature]` - Backend only
- `APEX-FRONTEND: [feature]` - Frontend only

### Quality Targets
- AIDAX: 80+ (content)
- SOFAX: 93+/110 (industry-leader quality)
- TUCHX: 60fps (touch interactions)
- CRUDX: All layers complete

### Lost Monster Entities
- **projects** - Core content items (portfolio work)
- **services** - Service offerings
- **testimonials** - Client reviews and feedback
- **contacts** - Enquiry contacts

### Lost Monster Brand Rules
- Dark backgrounds with gradients ONLY (no light page backgrounds)
- Cards use glassmorphism: `bg-white/5 backdrop-blur-md border`
- Dynamic colour via `style={{ color: color.accent }}`
- Typography: `text-6xl md:text-8xl lg:text-9xl` for heroes
- Personal "I" voice not corporate "we"
- Grid pattern background texture
- Key metrics always visible: 50+, 70%, 4.9/5, 2-4 wks
