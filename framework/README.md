## 💡 How to Use

### Option 1: Keep Hidden (Recommended)
```bash
# Framework stays as .framework (hidden folder)
project/
├── .framework/              # ← All framework files here
├── src/                     # Your app code
├── package.json
└── ...
```

**Pros**: Clean root, professional, follows conventions (like .git, .env)

### Option 2: Make Visible
```bash
# Rename to visible folder
mv .framework framework

project/
├── framework/               # ← All framework files here
├── src/                     # Your app code
├── package.json
└── ...
```

**Pros**: Easier to discover, visible in file tree

### Option 3: Root Level
```bash
# Move contents to root
mv .framework/* .
mv .framework/.ai .
mv .framework/.claude .
rm -rf .framework

project/
├── .ai/                     # Framework files in root
├── .claude/
├── templates/
├── src/                     # Your app code
└── ...
```

**Pros**: Direct access to files
