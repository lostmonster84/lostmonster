# Case Study Quality Assurance Checklist

Use this checklist before publishing any new case study to ensure it meets the 92+ rating standard.

---

## 📊 Metrics Validation

### Word Count & Reading Time
- [ ] **Total word count:** 1,400-1,600 words
- [ ] **Reading time:** 6-7 minutes (auto-calculated by `calculateReadingTime()`)
- [ ] **Total blocks:** 17-20 content blocks
- [ ] Run `analyzeCaseStudyStructure()` - score should be 90+

---

## 📖 Story Structure

### Act 1: The Arrival (Blocks 1-4)
- [ ] **Block 1:** Character introduced with full name
- [ ] **Block 1:** Context provided (job, vehicle use, how long owned)
- [ ] **Block 1:** Normal/good state established before problem
- [ ] **Block 2:** Short dramatic beat (10-20 words)
- [ ] **Block 3:** Customer dialogue with problem discovery
- [ ] **Block 3:** Highland location specificity (town name or terrain)
- [ ] **Block 4:** First image (problem visual with narrative caption)

### Act 2: The Discovery (Blocks 5-9)
- [ ] **Block 5:** Continuation or more customer perspective
- [ ] **Block 6:** Short emotional response (10-20 words)
- [ ] **Block 7:** "When we got it on the lift..." diagnosis
- [ ] **Block 7:** Highland-specific context (coastal, forestry, weather)
- [ ] **Block 8:** Stakes established (why this matters personally)
- [ ] **Block 9:** Pull quote positioned here (re-engages reader)

### Act 3: The Transformation (Blocks 10-15)
- [ ] **Block 10:** Solution revealed in short dramatic statement
- [ ] **Block 11:** Image grid with 2 process shots
- [ ] **Block 11:** Captions are narrative, not just descriptive
- [ ] **Block 12:** Technical work with specific parts/brands
- [ ] **Block 13:** Callout explaining technical "why"
- [ ] **Block 13:** Callout includes Highland context and data
- [ ] **Block 14:** Final steps and quality assurance details
- [ ] **Block 15:** Image grid with 2 result shots

### Act 4: The Resolution (Blocks 16-19)
- [ ] **Block 16:** Customer pickup with sensory details
- [ ] **Block 17:** Test drive with specific dialogue
- [ ] **Block 18:** Reflection on what repair achieves
- [ ] **Block 19:** Where-are-they-now satisfying ending
- [ ] **Block 19:** Callback to opening context

---

## 🎨 Content Quality

### Character & Story
- [ ] Customer has full name (not just "a customer")
- [ ] Customer has context (job, family, location, vehicle use)
- [ ] Specific details (not generic: "school runs" not "daily use")
- [ ] Emotional connection to vehicle shown
- [ ] Personal stakes established (safety, work, family, etc.)

### Highland Context
- [ ] Specific town mentioned (Inverness, Elgin, Lossiemouth, Grantown, Forres)
- [ ] Highland terrain/features referenced (Moray Firth, Cairngorms, Findhorn, Skye)
- [ ] Highland-relevant problem context (coastal salt, forestry tracks, wet winters)
- [ ] Local references feel authentic (not forced)

### Dialogue
- [ ] 3-4 customer dialogue moments integrated
- [ ] Dialogue feels natural and authentic
- [ ] Dialogue shows emotion and connection
- [ ] Pull quote is the strongest testimonial (saved for block 9)

### Technical Details
- [ ] Specific parts named (not "new chassis" but "genuine Land Rover galvanized chassis")
- [ ] Brand names included (Dinitrol ML3139, OEM, genuine Land Rover)
- [ ] Highland-specific choices explained (galvanized for coastal, heavy-duty for tracks)
- [ ] WildTrax fleet reference if applicable
- [ ] Technical details woven into narrative (not listed)

### Sensory Details
- [ ] 2-3 sensory moments included
- [ ] Examples: gleaming chassis, protective smell, tight feel, rain hammering
- [ ] Sensory details enhance immersion

---

## 🖼️ Visual Elements

### Image Placement
- [ ] **First image:** Block 3-4 (early visual interest)
- [ ] **Pull quote:** Block 8-9 (re-engagement point)
- [ ] **First image grid:** Block 11 (process shots)
- [ ] **Second image grid:** Block 15 (results)
- [ ] **No gaps:** Never more than 4-5 paragraphs without visual element

### Image Captions
- [ ] All captions are narrative (tell story context)
- [ ] Captions explain what this meant, not just what it shows
- [ ] Examples checked:
  - ❌ "Old chassis removed from vehicle"
  - ✅ "Six Highland winters written in rust and corrosion"

### Image Grids
- [ ] First grid shows process beginning + problem detail
- [ ] Second grid shows final stages + completed result
- [ ] Two images per grid (two-column layout)
- [ ] Images sourced from gallery array

---

## ✍️ Writing Style

### Paragraph Variation
- [ ] 3-4 short paragraphs (10-20 words) for dramatic beats
- [ ] Medium paragraphs (40-80 words) for standard narrative
- [ ] Long paragraphs (80-120 words) for technical detail
- [ ] Rhythm variation prevents monotony

### Narrative Flow
- [ ] Clear four-act structure followed
- [ ] Natural transitions between sections
- [ ] No abrupt topic changes
- [ ] Builds tension then resolves
- [ ] Satisfying closure at end

### Voice & Tone
- [ ] Professional yet passionate (not corporate)
- [ ] Confident without being arrogant
- [ ] Knowledgeable without condescension
- [ ] Specific without being verbose
- [ ] "Would a Porsche technician say this?" test passed

---

## 🎯 Callout Quality

### Educational Value
- [ ] Title asks "Why [Technical Decision]?"
- [ ] Content explains technical reasoning
- [ ] Highland-specific context included
- [ ] Specific data provided (3-5x faster, 10+ years, 25mm, etc.)
- [ ] 60-80 words (optimal length)
- [ ] Positioned at block 12-14 (after solution reveal)

### Examples of Good Titles
- ✅ "Why Galvanized?"
- ✅ "Why Coastal Vehicles Rust 3-5x Faster"
- ✅ "Why Ground Clearance Matters in the Cairngorms"
- ✅ "Why Discovery 3s Suffer Bulkhead Corrosion"

---

## 🔚 Ending Quality

### Resolution Elements
- [ ] Customer pickup scene with sensory details
- [ ] Test drive with specific route and reaction
- [ ] Reflection on deeper meaning of repair
- [ ] Where-are-they-now specific future use
- [ ] Callback to opening context
- [ ] Optional: Memorable final line or punch line

### Examples of Strong Endings
✅ "The last time we saw it, John was loading camping gear into the back. Heading to Skye for the weekend, he said. The Defender was going back to what it does best: Highland adventures, now with the chassis to match its spirit."

✅ "This Freelander 2 is ready for many more years of Cairngorms adventures. And those Duke of Edinburgh kids? They're in safe hands. Or rather, safe suspension."

## 🔍 SEO & Metadata

### Meta Information
- [ ] Meta description under 155 characters
- [ ] Meta description includes location and vehicle model
- [ ] Keywords list includes 4-6 relevant terms
- [ ] Keywords include Highland/Scotland locations
- [ ] Title format: "[Year] [Model] [Repair Type]"
- [ ] Subtitle is descriptive and compelling

## 🚀 Pre-Publish Final Checks

### Validation Tools
- [ ] Run `calculateReadingTime(story.contentBlocks)` - should be 6-7 minutes
- [ ] Run `analyzeCaseStudyStructure(story.contentBlocks)` - score should be 90+
- [ ] Check for warnings from analyzer
- [ ] Address any red flags before publishing

### Manual Review
- [ ] Read story aloud - does it flow naturally?
- [ ] Check for typos and grammar errors
- [ ] Verify all Highland locations are spelled correctly
- [ ] Confirm customer name is consistent throughout
- [ ] Test all image URLs load correctly

### Cross-Reference
- [ ] Customer name in opening matches pullQuote author
- [ ] Town in opening matches pullQuote context
- [ ] Duration mentioned in narrative matches details.duration
- [ ] Parts mentioned in narrative match details.partsUsed

## 📈 Post-Publish Monitoring

After publishing, track these metrics:

- [ ] **Scroll depth:** Target 80%+ (vs ~40% for technical layout)
- [ ] **Time on page:** Target 4+ minutes
- [ ] **Bounce rate:** Target <40%
- [ ] **"Continue Reading" clicks:** Target 20%+
- [ ] **Mobile engagement:** Should match desktop

If any metric underperforms, review story against this checklist to identify gaps.
