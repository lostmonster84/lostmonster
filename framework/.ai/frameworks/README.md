## Naming Convention

```
[BASE WORD 3-4 letters] + X = Framework Name

Examples:
- CODA + X = CODAX
- PLAN + X = PLANX
- SOPHIA → SOF + X = SOFAX
```

**Rules:**
- Always ends with X
- 4-5 letters max
- UPPERCASE
- X = eXecutable framework
