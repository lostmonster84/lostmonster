## Overview

This is a **complete enterprise-grade development framework** that combines:
- **AI partnership systems** for consistent, high-energy collaboration
- **16 universal planning frameworks** for structured development
- **4 specialized AI agents** for content, UI, review, and features
- **Enterprise standards** for coding, git, documentation, and security

- **Integration guides** for analytics, auth, CMS, payment, and communication
- **Utilities and automation** for helpers, hooks, validators, and git workflows
- **Industry messaging** templates for multiple sectors

## Setup Instructions

### Quick Setup (Copy to New Project)

```bash
# 1. Copy the entire framework
cp -r /path/to/this/project/twin /path/to/new-project

# 2. Rename the project folder
cd /path/to/new-project

# 3. Update the 6 project-specific files (see list above)
# Total time: 2-3 hours for thorough customization

# 4. Start building!
```

### Detailed Setup Process

#### Step 1: Copy Framework (5 minutes)
```bash
# Copy entire framework to new project
cp -r /path/to/twin /path/to/new-project
cd /path/to/new-project
```

#### Step 2: Define Your Project (30 minutes)
Answer these questions:
- What is the project? (product/service)
- Who are the users?
- What problem does it solve?
- What's the tech stack?
- What's the brand identity?

#### Step 3: Customize CLAUDE.md (10 minutes)
```bash
# Open CLAUDE.md
# Find and replace: [Project Name] → Your Project Name
# Update sections:
# - Current Project
# - Quick Reference (tech stack)
# - Project-specific context
```

#### Step 4: Create PRD.md (30-60 minutes)
```bash
# Copy template
cp PRD-TEMPLATE.md PRD.md

# - Target users
# - Core features
# - Technical requirements
# - Pricing strategy
```

cp PRO-TEMPLATE.md PRO.md

## Usage Guide

### Daily Workflow

#### 1. Planning a New Feature
```
1. Read: .ai/frameworks/CODA.md
2. Use: .ai/templates/feature-planning.md
3. Apply: CODA framework
4. Optional: Invoke feature-builder agent
5. Create: PLANX execution blueprint
```

#### 2. Building a UI Component
```
1. Read: .ai/templates/component-planning.md
2. Apply: Design Variations (create 5 options)
3. Get feedback: User selects preferred
4. Use: CODA planning for implementation
5. Optional: Invoke ui-builder agent
6. Build: Following design system
```

#### 3. Reviewing Code
```
1. Check: .ai/standards/coding/README.md
2. Check: .ai/standards/security/README.md
3. Optional: Invoke code-reviewer agent
4. Apply: Code review guidelines
5. Verify: All standards met
```

#### 4. Setting Up Integration
```
1. Navigate: integrations/[type]/README.md
2. Follow: Setup instructions
3. Use: Code examples
4. Apply: Best practices
5. Test: Integration working
```

#### 5. Writing Marketing Content
```
1. Read: .ai/frameworks/aida.md
2. Read: industry-messaging/[industry].md
3. Optional: Invoke handbook-generator agent
4. Apply: AIDA structure
5. Use: .ai/templates/case-study-checklist.md
```

### Framework Selection Guide

**Use this decision tree**:

```
Task: Complex feature or major change?
├─ Yes → Use CODA + PLANX
└─ No → Simple implementation

Task: UI/UX work or design?
├─ Yes → Use Design Variations + PIXELX
└─ No → Skip design frameworks

Task: CRUD feature?
├─ Yes → Use CRUDX
└─ No → Use appropriate framework

Task: Marketing content?
├─ Yes → Use AIDA + industry messaging
└─ No → Skip content frameworks

Task: Need quality audit?
├─ UI/UX → Use PIXELX
├─ Design → Use SOPHIA
└─ Code → Use code-reviewer agent

Unsure which framework?
→ Read: .ai/frameworks/FRAMEWORK-MAP.md
```
