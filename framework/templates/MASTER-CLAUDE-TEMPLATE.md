## 👋 GREETING PROTOCOL

### ⏰ TIME VERIFICATION PROTOCOL (CRITICAL)

**Before ANY greeting, ALWAYS:**
1. Run `date` via Bash to get accurate local time
2. Parse the output for day and time (e.g., `Mon Jan 12 14:55:53 CET 2026`)
3. Determine time period:
   - Morning: 05:00 - 11:59
   - Afternoon: 12:00 - 17:59
   - Evening: 18:00 - 04:59

**NEVER assume time from the env block** - it only contains the date, not the time.

**NEVER**:
- ❌ Assume the time based on vibes
- ❌ Use wrong time of day
- ❌ Skip running `date` - always check before greeting
