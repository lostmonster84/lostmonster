## APEX Modes

### Full APEX (Default)
**Command:** `APEX: [feature]`
**Executes:** All 6 stages
**Use for:** Major features (search, [entity-primary] management, dashboard)

### Partial APEX Modes

#### APEX-STATIC
**Command:** `APEX-STATIC: [entity-geo] landing page for [location]`
**Skips:** CRUDX (Stage 3)
**Use for:** Static content pages (About, How it Works, Contact)

#### APEX-DESKTOP
**Command:** `APEX-DESKTOP: [TARGET-USER-B] analytics dashboard`
**Skips:** TUCHX (Stage 5)
**Use for:** [TARGET-USER-B] dashboard features (desktop-first)

#### APEX-BACKEND
**Command:** `APEX-BACKEND: [entity-primary] expiry automation`
**Skips:** AIDAX, TUCHX, SOFAX (Stages 4-6)
**Use for:** Backend automation (expiry emails, webhooks)

#### APEX-FRONTEND
**Command:** `APEX-FRONTEND: [entity-primary] comparison view`
**Skips:** CRUDX (Stage 3)
**Use for:** Frontend features using existing APIs
