## What SHOWX Does

Creates branded social media cards for:
- LinkedIn posts (B2B — outreach, platform launches, feature announcements)
- Instagram squares (lifestyle — product showcases, visual impact)
- Twitter/X cards (broad — product updates, milestone announcements)
- Pitch deck slides (investor/partner — platform overview, metrics)

**Source material:** Device mockups generated by Playwright specs — browser windows, laptops, phones, multi-device composites.

## 5-Stage Process

```
SOURCE → BRIEF → COMPOSE → RENDER → DELIVER
  │         │        │         │         │
  │         │        │         │         └─ Output files + summary card
  │         │        │         └─ Playwright screenshots at exact dimensions
  │         │        └─ Inject mockup + copy into HTML template
  │         └─ Define headline/subheadline/CTA per platform
  └─ Find source mockups in screenshots/mockups/
```

### Stage 1: SOURCE
Find the right device mockup for the content. Check the mockups directory for:
- Browser window frames (best for LinkedIn, Twitter)
- Laptop frames (best for pitch decks)
- Phone frames (best for Instagram)
- Multi-device composites (best for pitch decks)

**Hard dependency:** If the required mockup doesn't exist, STOP. Flag with the exact command to generate it. Never generate dummy content. Never use a placeholder. The source must be a real screenshot.

### Stage 2: BRIEF
Define the copy for each platform card:
- **Headline:** 5-8 words maximum. Bold, benefit-driven, no jargon
- **Subheadline:** 1 sentence. Expands on the headline, adds context
- **CTA:** Action-oriented. Platform URL or specific action

Platform-specific brief rules:
| Platform | Tone | Headline Style | CTA Style |
|----------|------|---------------|-----------|
| LinkedIn | Professional, B2B | Feature/benefit focused | "Visit [domain]" |
| Instagram | Lifestyle, aspirational | Emotion focused | "Explore now" |
| Twitter | Punchy, direct | Product announcement style | "[domain]" |
| Pitch deck | Data-driven, authoritative | Platform positioning | Stats + URL |

### Stage 3: COMPOSE
Load the HTML template and inject:
1. Device mockup image (base64 data URL)
2. Headline text
3. Subheadline text (optional — hide if not provided)
4. CTA text (optional — hide if not provided)

Templates live at `tools/screenshots/social-{platform}.html`. Each has injectable slots: `#mockup-slot`, `#headline`, `#subheadline`, `#cta`.

### Stage 4: RENDER
Playwright screenshots at exact platform dimensions:
| Platform | Dimensions | Scale |
|----------|-----------|-------|
| LinkedIn | 1200x627 | 2x |
| Instagram | 1080x1080 | 2x |
| Twitter | 1600x900 | 2x |
| Pitch deck | 1920x1080 | 2x |

Output to `screenshots/social/` with naming convention: `{page}-{platform}.png`

### Stage 5: DELIVER
Present a summary card:
- Thumbnail of each generated card
- Platform, dimensions, file path
- Copy used (headline/subheadline/CTA)
- Any skipped cards (missing source mockups)

## Design Rules (Non-Negotiable)

1. **Real screenshots only** — no stock photos, no placeholders
2. **Project palette only** — use the brand colours from the Design Guide
3. **Project typography** — match the product's font and weight conventions
4. **One headline per card** — two messages = two cards
5. **No decorative flourishes** — AI Slop Test applies to social cards too
6. **Device frame = proof** — always leads with the device-framed version
7. **Platform dimensions are sacred** — exact pixels, no approximations
8. **Logo text only** — product name in uppercase bold, letter-spacing 3px. No logo file unless one exists
